# 公開測速資料更新

每天台灣時間 03:10 嘗試取得警政署國道固定式與臺中警方移動式公告。國道官方 TGOS 主機目前對 GitHub 託管執行環境回傳 HTTP 403，因此不具備獨立雲端更新國道資料的能力。來源、格式、筆數或下載失敗時保留該資料集的上次成功快照；部分失敗仍發布另一份成功快照，並使工作流程顯示失敗。來源資料不是即時勤務。

國道目前另有使用者電腦的 03:25 備援排程：在電腦開機、登入、網路及 GitHub CLI 驗證均正常時，先從 TGOS 下載並驗證，再同步本儲存庫並觸發 Pages 發布；電腦離線時不會執行。排程觸發不代表 Pages 已發布，需查看 deploy 工作與網站上的下載時間。

路口座標來自經雙向比對的固定參考快照；只有地點文字完全相同時套用。新增地點不會自動取得座標。GitHub Pages 由此工作流程直接發布；網站應保留本地快照備援。
